# dcngen

**A simulation-based, physics-gated fault-scenario generator for district
cooling networks** — and its first release artifact, **DCN-Bench v1**: 3,016
labelled thermal-hydraulic scenarios for GNN-based fault diagnosis.

`dcngen` turns a water-distribution topology from
[DiTEC-WDN](https://huggingface.co/datasets/rugds/ditec-wdn) into a closed-loop
district *cooling* network — every junction mirrored into supply and return
twins, a plant closing the loop, an ε-NTU heat-exchanger substation per
consumer — then couples an EPANET/WNTR hydraulic solve to a custom Lagrangian
thermal transport layer at a 10-minute timestep, injects labelled faults, and
validates every scenario against eight physics invariants before it enters the
dataset. Output: directed, temperature-carrying, fault-labelled graph time
series, PyTorch-Geometric-ready.

Three separable contributions live here:

1. **A method** — the DCN-ification of a consumptive water network into a
   closed supply/return cooling loop, transferable to any WDN
   corpus;
2. **A tool** — this generator: seeded scenario-plan sampling, coupled
   hydraulic–thermal solving, fault injection, a per-scenario physics gate,
   and reproducible Parquet records;
3. **An artifact** — DCN-Bench v1, generated by one command from one seed.

## Quickstart

Requires the DiTEC-WDN dump on local disk (path in `configs/default.yaml`)
and conda:

```bash
conda env create -f environment.yml
conda activate dcn-benchmark
pip install -e .

pytest                      # default suite,
pytest -m slow              # release assurance: end-to-end rows, reproducibility

python scripts/run_poc.py                        # one normal + one leak day, end to end
python scripts/generate_dataset.py --out data/v1 --workers 44   # the full release
```
